# 🚀 QuantTrader - Sistema de Trading Quantitativo

Sistema profissional de trading quantitativo com coleta de dados, processamento e estratégias automatizadas.

## 📊 Funcionalidades

- ✅ **Coleta de Dados**: Alpha Vantage, FRED, Forex
- ✅ **Processamento**: Indicadores técnicos, feature engineering
- ✅ **Estratégias**: Média Móvel, RSI, MACD
- ✅ **Backtesting**: Métricas de performance
- ✅ **Execução Automatizada**: Pipeline completo

## 🏗️ Estrutura
quant_trader/
